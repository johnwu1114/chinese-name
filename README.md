# 新生兒取名

## 1. 用途與範圍

本專案提供純前端的中文取名選字工具。使用者輸入單字姓氏、選擇生肖與筆劃組合，查看候選字、三才與五格結果。repo 包含靜態頁面、JavaScript 與 JSON 資料，沒有後端服務。

## 2. 如何開始

使用瀏覽器開啟 `index.html`，或在 repo 根目錄用 Python 靜態伺服器預覽後開啟頁面。頁面需要連線載入 jQuery 與遠端 JSON；啟動方式、資料來源與限制見[現況架構](docs/architecture.md#1-定位與啟動)。人工操作步驟見[工作流程](docs/workflow.md#22-人工預覽步驟)。

## 4. 緣起與參考

2012年為了大女兒取名研究了四種姓名學，隨手用 jQuery 寫成程式。  
我三個小孩的名字都是參考這個程式選字取名，選完字也有經過其他網站驗證，結果都還蠻滿意的。  

這是免費的取名程式，參考了以下四種姓名學：**周易文字筆劃五行**、**十二生肖姓名學**、**81數理姓名學**及**五行三才姓名學**。
