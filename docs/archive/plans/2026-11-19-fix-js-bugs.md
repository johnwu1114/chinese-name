# 修正 index.js 與 index.html 的程式缺陷

- 狀態：已完成
- 日期：2026-11-19
- 分支：`refactor`
- 來源：2026-11-19 跨模型 bug 審查（codex `gpt-6.1-sol` xhigh、agy `gemini-4-argon-high`，主線以 node vm 實跑回驗）

## 1. 範圍

只改 `index.js`、`index.html` 與受影響的現況文件。JSON 資料的筆劃與內容校正另案處理，本計畫不改資料檔。

| # | 缺陷 | 修正方式 |
| ---- | ---- | ---- |
| 1 | 候選字以中字與下字筆劃的聯集過濾，筆劃不符的字會出現在錯誤位置 | 依該位置筆劃過濾字典，移除全域 `selectedChars` |
| 2 | 三份基礎 JSON 載入前可操作，會丟 TypeError 或算出 0 劃組合 | 全部載入成功前停用輸入，失敗時顯示訊息 |
| 3 | 生肖請求亂序時，舊回應覆寫新結果 | 以請求序號忽略過期回應，並快取已載入的生肖資料 |
| 4 | 查無姓氏時保留舊姓氏顯示，並以 0 劃計算組合 | 停止計算、清空組合與結果、顯示查無訊息 |
| 5 | 改姓氏、清空姓氏或選回「請選擇」時，下游結果殘留 | 清空組合選單以外的結果區 |
| 6 | 切換生肖會重設組合選單，候選字仍是舊生肖 | 保留目前組合，以新生肖重新渲染候選字 |
| 7 | jQuery 使用協定相對 URL，`file://` 開啟時載入失敗 | 改為 `https://` |
| 8 | `for (key in results)` 建立隱式全域變數；陣列用 `for...in` 走訪 | 改用索引迴圈並宣告區域變數 |
| 9 | 排序比較器相等時回傳 -1 | 改為回傳 0 |
| 10 | 不喜不忌候選字倒序 | 改為依字典順序 |
| 11 | 缺 `<!DOCTYPE html>`；12 個 `<span ... />` 寫法 | 補 DOCTYPE，改為成對標籤 |
| 12 | 初始組合選項沒有 `value=""`；評語與描述用 `.html()` 插入；`get5EColor` 無預設分支；81 數理查表無防護 | 補空值、純文字改用 `.text()`、補預設分支、查無 81 數理時略過該組合 |
