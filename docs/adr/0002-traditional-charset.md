# 0002 字庫以台灣正體為準

- 狀態：接受
- 日期：2026-11-19
- 核准：John Wu 於 2026-11-19 在 Claude Code 對話中選擇「轉正體，無對應就刪」與「全補，表外的五行由模型判斷」。
- 舊識別：無
- 取代關係：部分取代 [ADR 0001](0001-kangxi-stroke-standard.md) 第 7 點（簡體殘字的判定與刪除）；ADR 0001 其餘仍有效。

## 背景與問題

字典 `chinese-characters.json` 原本由簡體字表轉換而來。2026-11-19 盤點時，字典仍有 280 字不在 Big5，包含大陸化學用字與簡體殘字。簡轉繁時，一對多的字只留下其中一個，例如有「鹹」沒有「咸」、有「後」沒有「后」。生肖表另有 382 個 Big5 字不在字典，所以永遠不會被推薦。前 100 大姓的「游、范、涂、袁」也不在字典，這四個姓的使用者只會看到「查無此姓氏」。

## 決策

1. 字典只收 Big5 有收錄的字，以 Big5 作為台灣正體的判準。
2. 不在 Big5 的字：Unihan `kTraditionalVariant` 有 Big5 正體、且正體不在字典 → 換成正體；正體已在字典或沒有 Big5 正體 → 刪除。
3. 先前因簡體而刪除的字，有 Big5 正體且正體不在字典 → 補回正體。
4. 生肖表出現、字典沒有的 Big5 字補進字典。
5. 新字的筆劃依 [ADR 0001](0001-kangxi-stroke-standard.md)。
6. 新字的字形五行依序判定：
   1. 部首在[慣例 §2.1](../conventions.md#21-字形五行) 表內 → 依表。
   2. 換成或補回的正體 → 沿用原字的五行。
   3. 其他 → 兩個不同家族的模型各自依字音與字義判斷，一致就採用；不一致時採字典現有表外部首字中，同一國語聲母的多數五行。

## 考慮過的替代方案

- 轉正體但保留不在 Big5 的罕用字：大陸化學用字等仍會出現在「不喜不忌」欄。
- 只補五行能依部首表判定的字（149 字加游、范、涂）：其餘 233 字與「袁」仍不在字典。
- 不補字或維持現狀：缺字問題不變。

## 理由與後果

- 字典的五行原本大致依字音判定。以國語聲母預測現有表外部首字的五行，吻合度約 75%；現有王部字也大多依聲母。所以模型不一致時，採聲母多數。
- 字典 7,032 → 7,166 字。刪除 280 字（含姓氏異體「凃」），換成正體 14 字，補回正體 22 字，補入生肖表缺字 378 字。
- 「游、范、涂、袁」可以查詢並產生組合。
- 限制：
  - Big5 不完全等於教育部常用字與次常用字表。
  - 231 個新字的五行由模型判斷：兩家一致 198 字，33 字採聲母多數。五行原始來源網站已失效，不是權威資料。
  - 生肖表的「嫺、碁」不在 Big5，所以不會顯示。
